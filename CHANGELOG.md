## [1.3.0] — 2026-08-11

Current product build.

### Behavior

- TextEdit-style launch: no home screen  
- Cold start without a file → Open panel only (no Untitled flash)  
- Open a `.md` with GruMD → that document only  
- File → New still creates a blank Untitled when you ask  
- Custom document controller blocks automatic Untitled  

### Features (1.3 line)

- Preview (default) + Split layouts  
- Find / Replace (Split mode), export HTML, print  
- Drag images → relative-path Markdown  
- Typography settings  
- Offline GFM preview, optional disk reload  

### Branding

- App icon: Q-version Gru with goggles + MD document  
- Classic pure-document icon kept under `docs/icons/`
