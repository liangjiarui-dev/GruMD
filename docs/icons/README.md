# App icon variants

GruMD icons stay **Apple-style productivity** with a quiet nickname nod to “Gru / 格鲁” (and a yellow wink for Minion/Bob energy). No licensed movie characters.

| File | Role |
|------|------|
| `app-icon-1.1-classic-1024.png` | **Archived** 1.1 classic document icon (kept on purpose) |
| `app-icon-goggles-bob-1024.png` | **Current shipping** — document + abstract dual-lens mark (yellow + silver) |
| `app-icon-chevron-gru-1024.png` | Alternate — tall chevron + yellow accent pill |
| `candidate-*.jpg` | Raw generation candidates |

To switch the shipping icon, regenerate AppIcon sizes from the chosen 1024 master into `GruMD/Assets.xcassets/AppIcon.appiconset/`.
